# myKantin & myPay Secure Gateway

Ekosistem pembayaran kantin sekolah berbasis **Smart POS**, **Dompet Digital Siswa**, **P2P Lending**, dan **Self-Hosted QRIS Payment Gateway** (EMVCo + HMAC-SHA512 Webhook).

## Cara Menjalankan
1. **myPay Gateway:** `cd myPay && npm install && node gateway.js`
2. **myKantin POS:** `cd myKantin && npm install && node server.js`
